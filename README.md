# Duel à l'Arc

Duel à l'arc en 3D pour deux téléphones. Les flèches ont un temps de vol et retombent avec la gravité, on peut esquiver un peu sur le côté, et le premier qui touche 2 flèches gagne.

Pour jouer : https://gab22222.github.io/duel-arc/

- Un joueur appuie sur **Créer une partie** et donne le code à l'autre, qui le tape puis appuie sur **Rejoindre**.
- Gauche : glisser pour se déplacer. Droite : maintenir pour bander l'arc, glisser pour viser, relâcher pour tirer.
- Aucun compte n'est nécessaire. Le multijoueur passe par un relais MQTT public (broker.emqx.io).
